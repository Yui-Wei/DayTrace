你可能想知道

开始前的小问题。

不配置 AI，也能正常使用吗？+

可以。自动记录、时间轴、统计和手动分类都不需要 AI。AI 分类和日报需要填写你自己的 API Key。

升级软件后，原来的记录还在吗？+

正常升级会保留记录、分类和设置。数据存放在用户目录，和程序文件分开；API Key 则保存在 Windows 凭据管理器中。

怎样更新到新版本？+

在软件的“关于”页面手动检查更新，也可以开启每天一次的自动检查。发现新版后可在软件内下载安装并重新启动。

怎样设置开机自启动？+

在“设置”里打开开机自启动开关即可，修改会立即生效。其他设置也会自动保存，不需要额外点击保存按钮。
